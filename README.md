# 天长的答案

个人博客源码，使用 Hexo 8 与 Stellar 主题构建，并由 GitHub Actions 发布到 GitHub Pages。

## 在线写作

访问 `https://9tianchang.github.io/Answer/admin/`，使用 GitHub 令牌登录后即可：

- 新建、编辑和删除文章
- 上传文章图片
- 修改首页标题、简介、欢迎语和页脚
- 编辑“关于本站”页面

每次保存都会提交到 `hexo` 分支，并自动更新线上网站。

## 分支说明

- `hexo`：博客源码与文章
- `master`：旧版静态站点历史存档；网站不再从此分支发布
